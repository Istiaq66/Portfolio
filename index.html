How I Ship

My own apps release themselves. Every push goes through a GitHub Actions pipeline, and nothing is built for release until it passes.

  1. Push to main
  2. Format & Analyze dart format, flutter analyze
  3. Test flutter test with coverage
  4. Check Secrets fails loudly if a key is missing
  5. Sign release keystore from encrypted secrets
  6. Release GitHub Release or Google Play
